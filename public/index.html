先把图片保存到手机，再打开 App 选择刚保存的图片。

iPhone/Android 会先出现系统分享面板，请点“存储图像/保存图片”。网页受手机系统限制，不能代替你点击 App 内的相机按钮；打开 App 后选择相册里最新一张即可。

手机使用、同步与通知

  1. 打开仪表盘手机 Safari 或 Chrome 打开当前网址，输入管理员给你的用户名和密码。
  2. 放到手机桌面iPhone：Safari“分享 → 添加到主屏幕”；Android：浏览器菜单“安装应用/添加到主屏幕”。
  3. 绑定自己的店铺在“账号管理”粘贴 Yahoo!フリマ 卖家主页链接，点“同步云端”，再在打开的 GitHub 页面点绿色“Submit new issue”。首次提交会绑定你的 GitHub 身份。
  4. 接收手机提醒填写自己的收件邮箱并同步；系统只发送你名下店铺的降价、提价和利润变化。管理员接收全部店铺。

管理员只需设置一次邮件服务

  1. 注册 Resend 并验证发件域名打开 Resend Domains，按页面提示把 DNS 记录加到自己的域名。
  2. 创建邮件密钥打开 Resend API Keys，创建密钥并复制；邮箱地址本身无法自动生成这个密钥。
  3. 放入 GitHub 加密设置打开本仓库 Actions Secrets，新增 RESEND_API_KEY（粘贴密钥）和 NOTIFY_FROM_EMAIL（例如 价格守卫 <notice@你的域名>）。普通用户不需要接触密钥，只填自己的收件邮箱。

没有启用邮件服务时，系统仍会使用 GitHub Issues 或 Telegram 降级提醒。邮箱和业务数据保存在加密文件中。
