手机使用、同步与通知

  1. 打开仪表盘手机 Safari 或 Chrome 打开当前网址，输入自己的用户名和密码。
  2. 放到手机桌面iPhone：Safari“分享 → 添加到主屏幕”；Android：浏览器菜单“安装应用/添加到主屏幕”。
  3. 同步输入录入成本、账号或通知邮箱后点“同步云端”，在打开的 GitHub 页面点绿色“Submit new issue”。工作流完成后，本页会自动出现新数据。
  4. 接收手机提醒在“账号管理”填写自己的邮箱并同步；系统只发送你负责店铺的价格变化。管理员接收所有店铺。未启用邮件服务时仍会使用 GitHub Issues 或 Telegram 降级提醒。
