手机使用、同步与通知

  1. 打开仪表盘手机 Safari 或 Chrome 打开当前网址，输入管理员给你的用户名和密码。
  2. 放到手机桌面iPhone：Safari“分享 → 添加到主屏幕”；Android：浏览器菜单“安装应用/添加到主屏幕”。
  3. 绑定自己的店铺在“账号管理”粘贴 Yahoo!フリマ 或 fril.jp/shop/ 卖家主页链接，点“同步云端”，再在打开的 GitHub 页面点绿色“Submit new issue”。首次提交会绑定你的 GitHub 身份。
  4. 接收提醒价格、成本和选品变化统一创建 GitHub Issue，不再发送邮件或 Telegram。
