手机使用与变动通知

  1. 打开仪表盘用手机 Safari 或 Chrome 打开当前网址，输入同一个仪表盘密码。
  2. 放到手机桌面iPhone：Safari 的“分享 → 添加到主屏幕”；Android：浏览器菜单中的“安装应用/添加到主屏幕”。
  3. 接收推送安装 GitHub 手机 App，在本仓库选择 Watch → Custom → Issues，并允许系统通知。价格守卫每次发现变化会自动创建 Issue。
  4. 查看通知记录打开 GitHub Issues。通知只显示变化数量，商品与利润仍需密码解锁。

也可在 GitHub Secrets 配置 Telegram；设置后变化提醒会优先发到 Telegram 私聊。
