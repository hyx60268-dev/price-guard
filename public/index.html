手机使用、同步与通知

  1. 打开仪表盘手机 Safari 或 Chrome 打开当前网址，输入同一个仪表盘密码。
  2. 放到手机桌面iPhone：Safari“分享 → 添加到主屏幕”；Android：浏览器菜单“安装应用/添加到主屏幕”。
  3. 同步输入录入成本或账号后点“同步云端”，在打开的 GitHub 页面点绿色“Submit new issue”。工作流完成后，本页会自动出现新数据。
  4. 接收手机提醒安装 GitHub App 并登录；价格变化会创建 Issue。若 App 仓库页没有 Watch 设置，可直接关注 Issues 页面，或配置 Telegram 获得更稳定的私聊提醒。
