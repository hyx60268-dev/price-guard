## 尚未完成的线上验收

- **闲鱼授权**：日志明确为详情 login_required。此次没有取得生产 Secrets，也没有替用户重新登录。需要有效会话后，由云端取得实际详情价格、独立卖家与新版本匹配证据；无法仅靠静态修复保证恢复。
- **生产覆盖**：所读生产状态为 628 件，本轮 Yahoo 实查49件，当前规则累计199件。没有声称全部商品都已人工核对或重新扫描。
- **生产人工成本**：没有解密密码，不能确认某一笔历史成本是否已永久遗失。代码修复防止再次丢失并提供可靠继承，不会编造原金额。
- **实际误判链接**：使用仓库既有真实问题记录与新增边界案例；未收到新的商品配对链接，不能断言所有当前在售商品都识别正确。
- **历史自动参考**：不把旧核验版本或失效证据强行迁移为有效采购成本。新的匹配版本会增加待核验数量，这是避免旧误判继续生效的代价。

## 发布风险与顺序

先审阅草稿 PR 与 CI，再合并发布。首次运行应检查：完整 state.json.enc 存在；同步 Issue 仅部署后关闭；账号墓碑不复活；新店铺触发扫描；status 中代码版本与部署一致。最后独立验收闲鱼成本，不以 Pages 成功代替成本成功。

自动参考优先于人工采购价是既有代码策略，本次保持；诊断已标出它与旧说明/注释的冲突。它可能让显示金额变化，但不等于人工记录被删除。
