# 指定商家追踪

在 `config/merchant-monitor.json` 的 `merchants` 中加入公开主页链接，或包含 `url` 和 `name` 的对象。支持 Yahoo!フリマ、Rakuma、Mercari 普通卖家主页。当前列表为空，待用户提供目标主页后启用真实监控。

每天由 GitHub Actions 检查；独立日程排队被替代时，价格任务也会补执行到期检查。日常比价先发布，商家检查最多占用额外 12 分钟的任务准入预算，正在读取的详情可能稍后结束。账户、人工成本与登录会话继续使用原来的加密状态和发布锁。保留每个主页的未完成/失败状态，不把部分读取说成全量完成。

筛选条件：标题或销售详情含“中国限定”或“海外限定”，且日元售价严格大于 4,999。价格为商品页面价格，文案中不推测运费或包邮。每个商品链接单独列出，不要求同款重复成交两次。

日期分为：

- 平台提供的上架或成交时间。
- 上次仍在售、本次明确已售：记录两个观测时间之间的区间。
- 首次看到已售、没有成交时间：单独归入日期未知，不能算今天/近30天成交。
- 商品从列表消失不等于成交。

文案使用《商品文案重写》的日文标题、商品说明、商品内容、状态和中文对照结构，作为草稿。缺失的数量、状态保留待核对提示；不会凭空声明正品、全新、限定资格或配送承诺。

闲鱼图片只采用通过同款详情核验的图片，并保留原商品链接。未核验时显示来源商家图片和找图待完成。找图共用闲鱼挑战冷却和访问节奏，不绕过验证。真实成本验收仍要求同款详情实价及至少两个独立卖家。
