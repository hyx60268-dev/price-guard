# 云端闲鱼会话续存

2026-09-23：扫描、选品和快速验收共用 `loadXianyuSession`，支持三段 Secret、GZIP 和旧 Base64。过去快速验收只读取三段 Secret，且各任务不会保存访问过程中更新的会话。

现在只有实际读到完整目标详情（标题、正文、唯一价格、卖家、图片）后才续存会话。存在登录要求或安全验证时不续存、不换身份重试。访问详情成功不等于同款核验成功；价格仍需通过原有规格、图片、多个卖家的核验。

会话用现有授权 Secret 派生的独立密钥加密，保存到 `state/xianyu-session.json.enc`，由现有 Actions 缓存保留。不会放进公开仪表盘目录，也不使用仪表盘密码加密。更换授权 Secret 后，旧缓存不能再加载。会话缓存最多使用七天，Cookie 的平台有效期仍然有效。

这只是保存平台已正常更新的登录状态，不是自动重新登录或绕过验证。没有有效会话时仍需账号正常授权。加载文件不代表登录成功；日志只输出来源和过期数量，不输出 Cookie 内容。

真实验收仍以对应 GitHub 运行出现合格人民币成本为准。当前交互式云端浏览器可读取一个此前报登录受限的详情，不能据此推断 GitHub Actions 会话也可访问，更不能把这个多规格价格区间当作单一同款成本。
